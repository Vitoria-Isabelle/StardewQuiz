# 🎮 StardewQuiz

Um web app interativo de perguntas e respostas ambientado no universo do jogo *Stardew Valley*. O projeto foi desenvolvido com foco em praticar a manipulação dinâmica de elementos via JavaScript e aplicar conceitos estruturados de estilização e responsividade no Front-End.



## 🎯 Objetivo do Projeto

O principal objetivo foi construir uma aplicação interativa que testasse os conhecimentos dos jogadores, indo além de um formulário estático comum. O desafio envolveu:
* Criar um fluxo dinâmico onde as perguntas e alternativas mudam na tela sem a necessidade de recarregar a página.
* Implementar um sistema de computação de pontuação em tempo real com base nas respostas selecionadas pelo usuário.
* Desenvolver uma interface imersiva e responsiva que adaptasse o design temático inspirado no jogo para diferentes tamanhos de tela.



## 🛠️ Tecnologias Utilizadas

A stack utilizada no desenvolvimento deste projeto consistiu em tecnologias fundamentais da Web:

* **HTML5:** Utilizado para a estruturação semântica de todo o conteúdo e das seções do quiz.
* **CSS3:** Responsável pela estilização personalizada, aplicando cores, tipografia e elementos visuais que remetem à identidade do jogo, além de garantir o layout responsivo.
* **JavaScript (ES6):** Utilizado para construir toda a lógica do sistema. Responsável pela manipulação do DOM, controle das estruturas condicionais de acertos/erros, gerenciamento do estado dos pontos e renderização dinâmica das perguntas.



## 🧠 Aprendizados Consolidados

A elaboração deste projeto trouxe vivências práticas fundamentais para minha evolução em desenvolvimento de sistemas:

* **Manipulação do DOM:** Compreensão profunda de como o JavaScript interage com o HTML e o CSS para modificar a interface em tempo real de acordo com as ações do usuário.
* **Lógica de Programação Aplicada:** Prática no controle de fluxos de dados, arrays de objetos (para armazenar as perguntas) e estruturas de repetição e condição.
* **UX/UI e Importância do Feedback:** Aprendizado sobre a experiência do usuário através da implementação de feedbacks instantâneos visuais (indicação de erro ou acerto na resposta) e o refinamento do design a partir de revisões no CSS após testes práticos.



### 🚀 Como testar o projeto no seu computador

1. Baixe a pasta com os arquivos do projeto aqui no GitHub.
2. Abra a pasta no seu computador.
3. Dê dois cliques no arquivo **index.html**. O quiz vai abrir direto no seu navegador de internet!
